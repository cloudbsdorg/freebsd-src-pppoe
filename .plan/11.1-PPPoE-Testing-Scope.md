## 1. Kernel Module Tests (`sys/netgraph/ng_pppoe_lb.c`)

### 1.1 Unit Tests (via ATF/Catch2 in-kernel simulation)

| Test ID | Description | Expected Result | Test Method |
|---------|-------------|-----------------|-------------|
| KERN-01 | Worker creation | Worker created with ACTIVE state | ngctl + sysctl check |
| KERN-02 | Worker state transitions | ACTIVE → DRAINING → PENDING_REMOVAL | ngctl + sysctl check |
| KERN-03 | Session routing (round-robin) | Sessions distributed evenly | Session count per worker |
| KERN-04 | Session routing (hash) | Same source → same worker | Hash consistency check |
| KERN-05 | Session routing (least-loaded) | Sessions go to lowest count | Verify distribution |
| KERN-06 | Governor scale-up trigger | Worker added when CPU > threshold | CPU spike + wait |
| KERN-07 | Governor scale-down trigger | Worker marked DRAINING when idle | Idle + wait |
| KERN-08 | Governor "change mind" | Pending removal canceled on spike | Scale-down then spike |
| KERN-09 | Draining worker skip | New sessions not assigned to DRAINING | Verify session routing |
| KERN-10 | Max workers enforcement | Cannot exceed max_workers | Attempt over-limit |
| KERN-11 | Min workers enforcement | Cannot go below min_workers | Attempt under-limit |
| KERN-12 | Session affinity preservation | Session stays on assigned worker | Hash replay |
| KERN-13 | Concurrent session access | No race conditions under load | Stress test |
| KERN-14 | Node destruction cleanup | All resources freed on shutdown | Memory check |
| KERN-15 | Sysctl read/write | All sysctls return correct values | Compare expected |

### 1.2 Sysctl Tests

| Test ID | Description | Command | Expected |
|---------|-------------|---------|----------|
| SYS-01 | Read current_workers | `sysctl net.graph.pppoe_lb.governor.current_workers` | Integer ≥ 0 |
| SYS-02 | Read active_workers | `sysctl net.graph.pppoe_lb.governor.active_workers` | Integer ≥ 0 |
| SYS-03 | Read draining_workers | `sysctl net.graph.pppoe_lb.governor.draining_workers` | Integer ≥ 0 |
| SYS-04 | Read total_sessions | `sysctl net.graph.pppoe_lb.governor.total_sessions` | Integer ≥ 0 |
| SYS-05 | Write min_workers | `sysctl net.graph.pppoe_lb.governor.min_workers=2` | Success |
| SYS-06 | Write max_workers | `sysctl net.graph.pppoe_lb.governor.max_workers=4` | Success |
| SYS-07 | Read per-worker state | `sysctl net.graph.pppoe_lb.workers.0.state` | 0, 1, or 2 |
| SYS-08 | Write per-worker state | `sysctl net.graph.pppoe_lb.workers.0.state=1` | Worker enters DRAINING |

## 8. Test Automation Scripts

### 8.1 Required Scripts

| Script | Location | Purpose | Priority |
|--------|----------|---------|----------|
| `ng_pppoe_lb_unit_test.sh` | `tests/netgraph/` | Run all kernel unit tests | P0 |
| `ng_pppoe_lb_regression_test.sh` | `tests/netgraph/` | Backward compatibility tests | P0 |
| `ng_pppoe_lb_integration_test.sh` | `tests/netgraph/` | Full session tests | P1 |
| `ng_pppoe_lb_stress_test.sh` | `tests/netgraph/` | Load and stress tests | P1 |
| `ng_pppoe_lb_config_test.sh` | `tests/netgraph/` | Configuration validation | P2 |
| `ng_pppoe_lb_perf_baseline.sh` | `tests/netgraph/` | Performance baseline | P1 |

### 8.2 Script Structure

Each test script should:
1. Check prerequisites (kernel module loaded, etc.)
2. Setup test environment
3. Run tests with clear pass/fail output
4. Cleanup test environment
5. Exit with appropriate code (0 = pass, 1 = fail)

### 8.3 Continuous Integration

| File | Purpose |
|------|---------|
| `tests/netgraph/Makefile` | Run all tests via `make test` |
| `tests/netgraph/run_tests.sh` | Master test runner |
| `tests/netgraph/ci_script.sh` | CI/CD integration script |
