## 1. Kernel Module Tests (`sys/netgraph/ng_pppoe_lb.c`)

### 1.1 Unit Tests (via ATF/Catch2 in-kernel simulation)

| Test ID | Description | Expected Result | Test Method |
|---------|-------------|-----------------|-------------|
| KERN-01 | Worker creation | Worker created with ACTIVE state | ngctl + sysctl check |
| KERN-02 | Worker state transitions | ACTIVE → DRAINING → PENDING_REMOVAL | ngctl + sysctl check |
| KERN-03 | Session routing (round-robin) | Sessions distributed evenly | Session count per worker |
| KERN-04 | Session routing (hash) | Same source → same worker | Hash consistency check |
| KERN-05 | Session routing (least-loaded) | Sessions go to lowest count | Verify distribution |
| KERN-06 | Governor scale-up trigger | Worker added when CPU > threshold | CPU spike + wait |
| KERN-07 | Governor scale-down trigger | Worker marked DRAINING when idle | Idle + wait |
| KERN-08 | Governor "change mind" | Pending removal canceled on spike | Scale-down then spike |
| KERN-09 | Draining worker skip | New sessions not assigned to DRAINING | Verify session routing |
| KERN-10 | Max workers enforcement | Cannot exceed max_workers | Attempt over-limit |
| KERN-11 | Min workers enforcement | Cannot go below min_workers | Attempt under-limit |
| KERN-12 | Session affinity preservation | Session stays on assigned worker | Hash replay |
| KERN-13 | Concurrent session access | No race conditions under load | Stress test |
| KERN-14 | Node destruction cleanup | All resources freed on shutdown | Memory check |
| KERN-15 | Sysctl read/write | All sysctls return correct values | Compare expected |

## 8. Test Automation Scripts

**Purpose:** Comprehensive unit tests for the PPPoE Load Balancer kernel module, testing worker management, session routing, governor functionality, and sysctl interface.

**Usage:**
```bash
./ng_pppoe_lb_unit_test.sh [--quick] [--verbose] [--stop-on-fail]
```

**Options:**
| Option | Description |
|--------|-------------|
| `--quick` | Skip timing-sensitive tests |
| `--verbose` | Show detailed output |
| `--stop-on-fail` | Stop on first failure |

**Exit Codes:**
| Code | Meaning |
|------|---------|
| 0 | All tests passed |
| 1 | One or more tests failed |
| 2 | Test environment error |

**Test Categories (33 tests):**

| Category | Tests | Description |
|----------|-------|-------------|
| KERN-01 to KERN-15 | 15 | Kernel module tests |
| SYS-01 to SYS-08 | 8 | Sysctl interface tests |
| NGCTL-01 to NGCTL-10 | 10 | ngctl command tests |

**Key Test Functions:**
```
test_kern_01_worker_creation()       - Test worker creation
test_kern_02_worker_state_transitions() - ACTIVE/DRAINING/PENDING_REMOVAL
test_kern_03_session_routing_rr()   - Round-robin algorithm
test_kern_04_session_routing_hash() - Hash-based algorithm
test_kern_05_session_routing_ll()   - Least-loaded algorithm
test_kern_06_governor_scale_up()   - Scale-up trigger

test_kern_15_sysctl_rw()           - Sysctl read/write
test_sysctl_read_write()            - All sysctls
```

**Color Output:**
- `[PASS]` - Green, test passed

```bash
# 1. Check prerequisites (root, modules, etc.)

# 2. Setup test environment
```

**Makefile Structure:**
```make
TESTS = unit_test regression_test config_test integration_test stress_test

test: $(TESTS)
	@echo "All tests completed"

unit_test:
	@./ng_pppoe_lb_unit_test.sh --quick

regression_test:
	@./ng_pppoe_lb_regression_test.sh --quick

config_test:
	@./ng_pppoe_lb_config_test.sh

integration_test:
	@./ng_pppoe_lb_integration_test.sh

stress_test:
	@./ng_pppoe_lb_stress_test.sh

clean:
	rm -rf /tmp/pppoe_lb_*

.PHONY: test $(TESTS) clean
```

**Master Test Runner (run_tests.sh):**
```bash
#!/bin/sh
# Master test runner - runs all test suites in order

TESTS="
    ng_pppoe_lb_unit_test.sh
    ng_pppoe_lb_regression_test.sh
    ng_pppoe_lb_config_test.sh
    ng_pppoe_lb_integration_test.sh
    ng_pppoe_lb_stress_test.sh
"

FAILED=0
for test in $TESTS; do
    echo "Running $test..."
    if ! ./$test; then
        FAILED=$((FAILED + 1))
        echo "FAILED: $test"
    fi
done

if [ $FAILED -gt 0 ]; then
    echo "$FAILED test(s) failed"
    exit 1
fi
echo "All tests passed"
```
