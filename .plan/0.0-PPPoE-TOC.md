### Build Targets

```bash
# Build kernel module
cd sys/modules/netgraph/pppoe_lb && make

# Build ngctl
cd usr.sbin/ngctl && make

# Build pppoed
cd libexec/pppoed && make

# Build all
cd sys/modules/netgraph && make pppoe_lb
```

### Sysctl Namespace

```
net.graph.pppoe_lb.*
  ├── node.*              (node configuration)
  ├── session.*           (session limits)
  ├── algorithm.*         (load balancing algorithm)
  ├── governor.*          (auto-scaling governor)
  └── workers.*           (per-worker state)
```
