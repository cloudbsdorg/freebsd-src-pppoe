## 8.0.2 Detailed Enhancement Ideas

### Per-Worker CPU Affinity

Pin each worker to a specific CPU core for cache locality:

```bash
# Future: Set CPU affinity
sysctl net.graph.pppoe_lb.workers.0.affinity=0
sysctl net.graph.pppoe_lb.workers.1.affinity=1
```

### NUMA Awareness

When creating workers, consider NUMA topology:

```bash
# Future: Enable NUMA awareness
sysctl net.graph.pppoe_lb.numa_aware=1
```

### eBPF Integration

Use eBPF for custom load balancing algorithms:

```bash
# Future: Load custom eBPF program
ngctl msg lb: load_bpf /path/to/program.o
```

### External Monitoring

```bash
# Example: Prometheus node_exporter integration
```
