# Tooling & Management

## 6.1.1 ngctl Commands

The `ngctl` utility provides commands for managing the PPPoE load balancer:

### Available Commands

| Command | Description |
|---------|-------------|
| `ngctl pppoe_lb help` | Show help message |
| `ngctl pppoe_lb addworker <node>` | Add a new worker |
| `ngctl pppoe_lb rmworker <node> <id>` | Remove a worker |
| `ngctl pppoe_lb setalgorithm <node> <0|1|2>` | Set algorithm |
| `ngctl pppoe_lb showstats <node>` | Show statistics |
| `ngctl pppoe_lb showworkers <node>` | Show workers |
| `ngctl pppoe_lb setdebug <node> <level>` | Set debug level |

## 6.1.2 rc.conf Integration

### Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `pppoed_enable` | NO | Enable pppoed daemon |
| `pppoed_flags` | — | Additional flags |
| `pppoed_interface` | — | Interface to bind |
| `pppoed_workers` | 1 | Number of workers |
| `pppoed_governor_enable` | NO | Enable auto-scaling |
| `pppoed_governor_min` | 1 | Minimum workers |
| `pppoed_governor_max` | 0 | Maximum workers (0=auto) |

---

## 6.1.3 Example Configuration

```bash
# /etc/rc.conf
pppoed_enable="YES"
pppoed_interface="em0"
pppoed_flags="-L -w 4"
pppoed_governor_enable="YES"
pppoed_governor_min="2"
```
