# Testing Strategy

## 4.0.1 Testing Overview

Testing is divided into multiple levels to ensure reliability before production deployment.

---

## 4.0.2 Test Levels

### Level 1: Build Verification

| Test | Description | Location |
|------|-------------|----------|
| Compilation | Verify all components compile | `sys/modules/netgraph/pppoe_lb/` |
| Syntax check | Verify shell scripts | `sh -n *.sh` |

### Level 2: Unit Tests

| Test | Description | Status |
|------|-------------|--------|
| Worker creation | Verify worker adds correctly | COMPLETED |
| Session affinity | Verify same session → same worker | PENDING |
| Algorithm selection | Verify round-robin vs hash | PENDING |
| Worker removal | Verify graceful shutdown | PENDING |

### Level 3: VM Integration Tests

| Test | Description | Status |
|------|-------------|--------|
| Basic VM test | Single client connecting | PENDING |
| Multi-client test | Multiple clients | PENDING |
| Load test | High session count | PENDING |

### Level 4: Stress Tests

| Test | Description | Status |
|------|-------------|--------|
| Session churn | Rapid connect/disconnect | PENDING |
| Long-running stability | 24+ hour test | PENDING |

## 4.0.4 Safety Requirements

⚠️ **IMPORTANT:** Kernel module must NOT be loaded on bare metal. All integration tests must be run in a VM environment.
