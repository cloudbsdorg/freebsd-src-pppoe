# Sysctl Interface Reference

## 5.1.1 Complete Sysctl Hierarchy

```
net.graph.pppoe_lb
├── debug                              # Debug level (0-5)
├── node.hook                         # Node hook name
│
├── session.max                       # Max sessions per worker
├── session.total                     # Total active sessions (read-only)
│
├── algorithm                         # 0=round-robin, 1=hash, 2=least-loaded
├── algorithm.name                     # Algorithm name (read-only)
│
├── governor.enabled                 # Governor enabled (0/1)
├── governor.mode                    # 0=manual, 1=auto
├── governor.min_workers             # Minimum workers
├── governor.max_workers             # Maximum workers (0=mp_ncpus)
├── governor.poll_interval           # Poll interval (seconds, range 1-60)
├── governor.cpu_threshold           # Scale up at CPU %
├── governor.cpu_low_threshold       # Scale down at CPU %
├── governor.sessions_per_worker     # Target sessions per worker
├── governor.drain_timeout           # Drain timeout (seconds)
├── governor.cpu_cores_max          # Detected CPU cores (read-only)
│
├── governor.current_workers         # Current worker count (read-only)
├── governor.active_workers         # ACTIVE workers (read-only)
├── governor.draining_workers       # DRAINING workers (read-only)
├── governor.pending_removals       # Workers pending removal (read-only)
├── governor.sessions              # Total sessions (read-only)
├── governor.avg_sessions_worker   # Avg sessions per worker (read-only)
├── governor.cpu_usage             # Current CPU usage % (read-only)
├── governor.cpu_avg               # Average CPU usage % (read-only)
├── governor.last_decision         # Last decision (read-only)
├── governor.last_reason           # Last decision reason (read-only)
│
├── workers.count                   # Worker count (set to add/remove workers)
├── workers.{id}.state             # Worker state: 0=ACTIVE, 1=DRAINING, 2=PENDING_REMOVAL (READ/WRITE)
├── workers.{id}.sessions          # Sessions on worker (read-only)
├── workers.{id}.last_activity     # Last activity timestamp (read-only)
├── workers.{id}.uptime           # Worker uptime in seconds (read-only)
│
├── stats.packets_in               # Total packets in
├── stats.packets_out              # Total packets out
├── stats.bytes_in                 # Total bytes in
├── stats.bytes_out                # Total bytes out
├── stats.session_creates          # Sessions created
├── stats.session_teardowns        # Sessions torn down
└── stats.scale_events             # Scaling events
```

## 5.1.2 Configuration Sysctls

### General Configuration

| Sysctl | Type | Default | Description |
|--------|------|---------|-------------|
| `debug` | RW | 0 | Debug level (0=off, 5=max) |
| `session.max` | RW | 65535 | Maximum sessions per worker |
| `algorithm` | RW | 1 | Load balancing algorithm |
| `algorithm.name` | RO | "hash" | Algorithm name |

**Algorithm values:**
- 0: round-robin
- 1: hash (default)
- 2: least-loaded

---

### Governor Configuration

| Sysctl | Type | Default | Description |
|--------|------|---------|-------------|
| `governor.enabled` | RW | 0 | Enable governor (0=disabled, 1=enabled) |
| `governor.mode` | RW | 0 | Governor mode (0=manual, 1=auto) |
| `governor.min_workers` | RW | 1 | Minimum workers |
| `governor.max_workers` | RW | 0 | Maximum workers (0=mp_ncpus) |
| `governor.poll_interval` | RW | 5 | Poll interval (1-60 seconds) |
| `governor.cpu_threshold` | RW | 80 | Scale up at CPU % |
| `governor.cpu_low_threshold` | RW | 30 | Scale down at CPU % |
| `governor.sessions_per_worker` | RW | 500 | Target sessions per worker |
| `governor.drain_timeout` | RW | 30 | Drain timeout (seconds) |

## 5.1.3 Per-Worker State Control (READ/WRITE)

### State Values

| Value | Name | Description |
|-------|------|-------------|
| 0 | ACTIVE | Normal operation, accepts new sessions |
| 1 | DRAINING | No new sessions, waiting for existing to complete |
| 2 | PENDING_REMOVAL | Empty, marked for removal |

### Manual Worker Management

```bash
# Mark a worker for drain (set state to DRAINING=1)
sysctl net.graph.pppoe_lb.workers.2.state=1

# Cancel drain and return worker to service (set state to ACTIVE=0)
sysctl net.graph.pppoe_lb.workers.2.state=0

# Mark empty worker for removal (set state to PENDING_REMOVAL=2)
sysctl net.graph.pppoe_lb.workers.2.state=2
```

### State Transition Rules

- `0 (ACTIVE)` → `1 (DRAINING)` or `2 (PENDING_REMOVAL)` ✓
- `1 (DRAINING)` → `0 (ACTIVE)` (cancel drain) or `2 (PENDING_REMOVAL)` ✓
- `2 (PENDING_REMOVAL)` → `0 (ACTIVE)` (re-activate) or `1 (DRAINING)` ✓

**Safety:** If worker has active sessions and you set `PENDING_REMOVAL`, state stays `DRAINING` until sessions drain.

## 5.1.5 Example Usage

### Basic Setup

```bash
# Check current configuration
sysctl net.graph.pppoe_lb

# Set hash-based load balancing
sysctl net.graph.pppoe_lb.algorithm=1

# Set maximum 4 workers
sysctl net.graph.pppoe_lb.workers.count=4
```

### Enable Auto-Scaling

```bash
# Enable governor
sysctl net.graph.pppoe_lb.governor.enabled=1
sysctl net.graph.pppoe_lb.governor.mode=1

# Configure limits
sysctl net.graph.pppoe_lb.governor.min_workers=2
sysctl net.graph.pppoe_lb.governor.max_workers=0   # 0 = auto (mp_ncpus)

# Adjust thresholds
sysctl net.graph.pppoe_lb.governor.cpu_threshold=80
sysctl net.graph.pppoe_lb.governor.cpu_low_threshold=30
sysctl net.graph.pppoe_lb.governor.sessions_per_worker=500
```

### Manual Worker Management

```bash
# View worker status
sysctl net.graph.pppoe_lb.workers.0.state
sysctl net.graph.pppoe_lb.workers.0.sessions

# Manually drain worker 2
sysctl net.graph.pppoe_lb.workers.2.state=1

# Cancel drain
sysctl net.graph.pppoe_lb.workers.2.state=0

# Mark empty worker for removal
sysctl net.graph.pppoe_lb.workers.2.state=2
```

### Monitoring

```bash
# View all stats
sysctl net.graph.pppoe_lb.stats

# View governor status
sysctl net.graph.pppoe_lb.governor

# View all workers
sysctl net.graph.pppoe_lb.workers
```
