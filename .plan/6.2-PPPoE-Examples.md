## 6.2.2 Basic 2-Worker Setup

```bash
# Create load balancer node
ngctl mkpeer em0 hook pppoe_lb lb

# Create 2 worker nodes
ngctl mkpeer lb: pppoe lower w1
ngctl mkpeer lb: pppoe lower w2

# Configure
ngctl msg lb: setalgorithm 1
ngctl msg lb: setworkers 2
```

---

## 6.2.3 Auto-Scaling Setup

```bash
# Enable governor
sysctl net.graph.pppoe_lb.governor.enabled=1
sysctl net.graph.pppoe_lb.governor.mode=1

# Set limits (auto = CPU cores)
sysctl net.graph.pppoe_lb.governor.min_workers=2
sysctl net.graph.pppoe_lb.governor.max_workers=0

# Tune thresholds
sysctl net.graph.pppoe_lb.governor.cpu_threshold=80
sysctl net.graph.pppoe_lb.governor.cpu_low_threshold=30
sysctl net.graph.pppoe_lb.governor.sessions_per_worker=500
```
