## 1. Overview

### 1.1 Purpose

This document defines the comprehensive documentation plan for the Multithreaded PPPoE Load Balancer implementation. It maps existing documentation (man pages, handbook) to a structured plan that ensures completeness, consistency, and discoverability.

### 1.2 Scope

The documentation covers:

- **Kernel Module**: `ng_pppoe_lb` netgraph node type
- **Userland Daemon**: `pppoed` with multi-worker support
- **Userland Tools**: `ngctl` pppoe_lb subcommands
- **Testing Tool**: `pppoetest` diagnostic and testing utility
- **Configuration**: Example configurations, rc.conf integration
- **Monitoring**: Sysctl interface, monitoring scripts

### 1.3 Goals

1. Ensure all features are documented
2. Provide clear, actionable examples
3. Support multiple user skill levels
4. Enable easy discovery of information
5. Maintain consistency across all documentation

## 5. Audience Analysis

### 5.1 Primary Audiences

| Audience | Skill Level | Use Case | Priority |
|----------|-------------|----------|----------|
| **ISP Administrators** | Intermediate-Advanced | Deploy and manage production PPPoE servers | P0 |
| **Network Engineers** | Advanced | Configure load balancing, troubleshoot issues | P0 |
| **System Administrators** | Intermediate | Install, monitor, maintain PPPoE services | P1 |
| **Developers** | Advanced | Extend, debug, integrate with other tools | P2 |
| **DevOps/Automation** | Intermediate-Advanced | Script deployments, integrate with CI/CD | P2 |

### 5.2 Documentation by Audience

| Audience | Primary Doc | Secondary Docs | Depth |
|----------|-------------|----------------|-------|
| ISP Administrators | Handbook 30.7 | Man pages, Examples | Comprehensive |
| Network Engineers | Man pages | Sysctl reference, Examples | Technical |
| System Administrators | Handbook, Examples | Man pages | Practical |
| Developers | Source code, Plan docs | Man pages | Reference |
| DevOps | Examples, Scripts | Handbook | Implementation |

### 5.3 User Journeys

**Journey 1: New Deployment**
```
1. Read Handbook Section 30.7 (Overview)
2. Choose configuration (Basic vs Auto-scaling)
3. Follow example configuration
4. Configure rc.conf
5. Start and verify
6. Set up monitoring
```

**Journey 2: Troubleshooting**
```
1. Identify symptom
2. Check handbook troubleshooting section
3. Use pppoetest diagnostic mode
4. Review sysctl hierarchy
5. Check logs
6. Contact support (if needed)
```

**Journey 3: Performance Tuning**
```
1. Read sysctl interface documentation
2. Understand governor parameters
3. Review monitoring examples
4. Implement custom monitoring
5. Tune thresholds based on load patterns
```

## 7. Cross-Reference Strategy

### 7.1 Cross-Reference Requirements

All documentation must cross-reference related documents:

| Document | Must Reference |
|----------|----------------|
| `ng_pppoe_lb.4` | `pppoed.8`, `ngctl.8`, `pppoetest.8`, Handbook 30.7 |
| `pppoed.8` | `ng_pppoe_lb.4`, `ngctl.8`, Handbook 30.7 |
| `pppoetest.8` | `ng_pppoe_lb.4`, `pppoed.8`, Handbook 30.8 |
| Handbook 30.7 | `ng_pppoe_lb.4`, `pppoed.8`, all example configs |
| Examples | Relevant man pages |

### 7.2 Cross-Reference Format

**mdoc cross-references:**
```mdoc
See Xr ng_pppoe_lb 4 ,
Xr pppoed 8 .
```

**Markdown cross-references:**
```markdown
See [ng_pppoe_lb(4)](ng_pppoe_lb.4.md) and [pppoed(8)](pppoed.8.md).
```

**AsciiDoc cross-references:**
```asciidoc
See man:ng_pppoe_lb[4] and man:pppoed[8].
```

### 7.3 Index Entries

Every man page must include appropriate `.Sh INDEX` entries:

```mdoc
.Sh INDEX
The following topics are covered in this manual page:
.Bl -tag -width indent
.It Sy Hooks
Description of node hooks
.It Sy Control Messages
Netgraph control messages
.It Sy Sysctl Variables
Runtime configuration variables
.El
```

## 8. Style Guide

### 8.1 Writing Standards

| Standard | Requirement |
|----------|------------|
| **Voice** | Active voice, imperative mood for instructions |
| **Tense** | Present tense for descriptions, future for plans |
| **Audience** | Assume intermediate Unix knowledge |
| **Clarity** | Short sentences, clear terminology |
| **Examples** | Working, tested examples only |

### 8.2 Formatting Conventions

| Element | Format | Example |
|---------|--------|---------|
| Commands | Monospace | `pppoed -L -w 4 em0` |
| Paths | Monospace | `/etc/rc.conf` |
| Sysctls | Monospace | `net.graph.pppoe_lb.governor.enabled` |
| Options | Bold | `-L` flag |
| Files | Italics | `_index.adoc` |
| Variables | Monospace | _interface_, _workers_ |

### 8.3 Example Format

```mdoc
.Ss Example
Load the kernel module:
.Bd -literal -offset indent
kldload ng_pppoe_lb
.Ed
.Pp
Create a load balancer topology with 4 workers:
.Bd -literal -offset indent
ngctl name . pppoe_lb0
ngctl mkpeer pppoe_lb0: pppoe worker0
ngctl mkpeer pppoe_lb0: pppoe worker1
ngctl mkpeer pppoe_lb0: pppoe worker2
ngctl mkpeer pppoe_lb0: pppoe worker3
.Ed
```

### 8.4 Terminology

| Term | Definition | Usage |
|------|------------|-------|
| Worker | ng_pppoe node handling sessions | Consistent throughout |
| Governor | Auto-scaling controller | Consistent throughout |
| Session | Active PPPoE connection | Consistent throughout |
| Load Balancer | ng_pppoe_lb node | Consistent throughout |
| Node | Netgraph node | From netgraph docs |

## Appendix B: Style Quick Reference

| Do | Don't |
|----|-------|
| Use `pppoed -L -w 4` | Use "run pppoed with load balancing" |
| Use `sysctl net.graph.pppoe_lb...` | Use "set the sysctl" |
